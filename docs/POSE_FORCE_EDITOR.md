# 姿勢補正のゲーム内編集（ksPlugPoseForce）

量だけを調整する場合は [使い方](POSE_FORCE_GUIDE.md) を参照。既定は EnablePoseForce=false・量０・キー未割り当て。

## 画面とキー

ConfigurationManager の `ksPlug Pose Force` → `PoseForce` から次の画面を開く。両方を同時に表示でき、表示位置は別々に保存する。

| ボタン | 用途 | 開閉キー |
|---|---|---|
| 調整の画面を開く | 補正量と有効／無効だけを操作する小さい画面 | WindowKey（既定は未割り当て） |
| 値の編集画面を開く | 数値・手の付け先・保存などの編集 | EditorWindowKey（既定は未割り当て） |

２つのキーは別のキーに割り当てる。２人・３人の挿入（アナルを含む）で補正・編集できる。表に値がない体位・状態にも項目を追加できる。

## 値を変更する

補正値はプラグインに入っていない。値は kPlug の書き出しの取り込みか、この画面での追加で用意する。将来プラグインに入る値（内蔵の値）と同じ補正項目があれば、利用者の `PoseForce.tsv` の値を使う。kPlug を更新したときは、新しい書き出しを取り込める。MMF などの新しい形式・役割には対応していない。

1. EnablePoseForce をオンにし、補正量を０より大きくする。
2. 人（２人用は女・男、３人用は女１・男・女２）と、編集する状態を選ぶ。女１・女２は参加者の順番で、挿入の相手が切り替わっても入れ替わらない。「今の状態に追従」は最初はオン。特定の状態を編集し続けたいときは切る。状態の一覧の ● は、その人の欄がある状態。選んでもゲームのアニメーションは切り替わらない。
3. 数値、−・0・＋、スライダーで値を変える。値は補正量１のときの最大値で、実際には今の補正量を掛ける。
4. 編集は未保存のままプレビューする。選んだ状態とゲームの状態が違う場合は、ゲームがその状態になったときに見た目に出る。保存するまで TSV は書き換えない。

位置は m、基本の範囲 ±0.5、ボタンは ±0.01。回転は度、基本の範囲 ±60、ボタンは ±1。spine_roll は X だけ。元の値が範囲の外でも、開いただけでは切り詰めない。入力中の `-` などは一時的に表示でき、数値として読める部分までを反映する。読めない入力や NaN・Infinity は反映しない。

文字の入力中は、補正量のキーとゲームのキーを止める。マウスが画面の上にある間は、下の Hシーンの UI とカメラの入力も止める。全部の画面を閉じると元に戻る。

付け先・複写・基準への復元・取り込みは、別のダイアログで操作する。開いている間は背面の画面とゲームの操作を止め、編集する状態の自動追従を一時止める。「閉じる（Esc）」か Esc で閉じる。体位・Hシーンが変わると、付け先・複写・復元のダイアログは閉じる。取り込みのダイアログは体位に依存しないので残る。

## 欄・手の付け先・複写

- 「補正項目（位置・回転・手の IK）を追加」で、対応している項目を選ぶ。数値の初期値は０。ここで足すのは骨やアセットそのものではなく、それらへの補正の設定。
- 「この欄を消す」は、この人・状態の欄だけを消す。取り込んだ欄・内蔵の欄も消せる。保存すると削除の指定が残り、再起動や再取り込みの後も有効。
- 手の欄の「付け先を選ぶ…」で別ダイアログを開く。`female:骨名`・`male:骨名`・`female2:骨名` の候補を２列で表示し、人と骨の名前で絞り込める。female2 は３人用で選ぶ。候補は表にある付け先と主な骨で、直接入力もできる。今のキャラに骨が見つからない付け先は適用しない。機能をオフにしていても、人の骨が読み込まれていれば選べる。
- 手の欄を足すと、見つかった候補を仮の付け先にする。必要な付け先に選び直してから保存する。
- 「他の状態へ写す…」で別ダイアログを開き、その欄の値と手の付け先を、同じ人の選んだ状態へ写す。写し先に同じ欄があれば置き換える。これも保存するまでは未保存。

## 保存・取消・復元

| 操作 | 結果 |
|---|---|
| 保存 | 変えた欄を origin=user として PoseForce.tsv に保存。前のファイルは .bak に残す。変更が無ければ書かない |
| 元に戻す（保存前へ） | 編集を始めた時、または最後に保存した時の値に戻す。ファイルは変えない |
| kPlug・内蔵の値に戻す… | 別ダイアログで復元元を確かめ、「この体位の手動編集を基準に戻す（未保存）」を実行。この体位の user 行と削除の指定を取り除き、選んだファイル（kPlug の書き出しか共有データ）の同じ体位の行を重ねる。同じダイアログの「内蔵の値を自分の値にする」は、この体位の内蔵の値を自分の値として写す（kPlug の値の代わりに内蔵の値を使いたいとき。内蔵の値がある体位だけ）。どちらも保存するまでは未保存 |
| この体位を補正しない／する | 体位全体を止める・戻す（プレビュー）。「保存」で残る |
| 閉じる | 未保存の編集とプレビューを保ったまま画面を閉じる |

保存では、ほかの体位・人・未対応の欄も残す。編集中に外からファイルが変えられていた場合や、保存先を更新できない場合は保存を止め、編集を保ったまま理由を表示する。外での変更を読み込むときは、必要な編集の値を控えてから「値の表を読み直す」を使う。

基準に戻すときのファイルは、取り込みと同じ一覧（`import` フォルダと、直下の `kPlugPose_*.tsv`）から選ぶ。取り込んだ直後はそのファイル、それ以外は更新日時の新しい順の先頭を選ぶ。ファイルが無い場合は、user 行を取り除いて、内蔵の値と残っている取り込んだ値を基準にする。

この復元は、今の体位の手動の編集だけが対象。ほかの体位・未編集の kplug 行は残し、補正量・UseHandIK などの設定は戻さない。TSV 全体を .bak に戻す操作でもない。押し間違えた場合は、保存する前に「元に戻す（保存前へ）」で取り消せる。

**体位か Hシーンを変えると、未保存の編集は捨ててログに記録する。** 表の読み直し・取り込みでも未保存の編集は捨てる。残したい編集は、その前に保存する。

## 取り込みと自分の値の書き出し

ConfigurationManager か編集画面の「書き出しの取り込み画面を開く…」で専用のダイアログを開く。開くだけでは取り込まない。取り込むファイルは `BepInEx/config/ksPlugPoseForce/import/` に置く（kPlug の書き出し・ほかの人の共有データ）。自分の `PoseForce.tsv` は一覧に出ない。

ファイルは更新日時の新しい順で、種類（kPlug の書き出し／共有データの名前）と行の数が並ぶ。１件でも、選んだ名前を確かめて「選んだファイルを取り込む」を押す。結果・件数・警告・エラーは、同じダイアログの「取り込み状況」に表示する（この起動中の直近 80 件）。取り込みに成功すると PoseForce.tsv を更新し、未保存の編集を捨てる。同じ項目は、自分の値 ＞ 共有データ ＞ kPlug の値 ＞ 内蔵の値 の順に使う（[値の表](POSE_FORCE_TABLE_FORMAT.md)）。

「自分の値の書き出し…」（編集画面の下、または ConfigurationManager）で、データの名前・作者・範囲（全体位／今の体位）を選び、自分で編集して保存した値を `export/PoseForceShare_<名前>_<日時>.tsv` に書き出す。kPlug の書き出しと同じ値の行は書き出さない。保存していない編集は含まない（[使い方](POSE_FORCE_GUIDE.md) の「自分の値を書き出す」）。

## 動作の確かめ方の例

1. 正常位の InsertIdle で、女の root_pos の Y を少し変え、見た目の変化と「元に戻す」を確かめる。少し変えて保存し、Hシーンを出て入り直しても値が残るか確かめる。
2. 欄の追加・削除、他の状態への複写、手の付け先の選択を試す。状態を固定したいときは「今の状態に追従」を切る。
3. 体位を止める・戻すを保存して確かめる。書き出しから基準に戻す操作と「元に戻す」も確かめる。
4. 数値の入力中にキーが効かないこと、未保存のまま体位を変えたときに編集が捨てられることを確かめる。

TSV の列と骨の対応は [値の表](POSE_FORCE_TABLE_FORMAT.md)、UseHandIK の範囲と診断は [手 IK](POSE_FORCE_HAND_IK.md)。
