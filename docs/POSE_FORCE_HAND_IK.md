# 姿勢補正の手 IK（ksPlugPoseForce）

## UseHandIK の範囲

ConfigurationManager の `PoseForce / UseHandIK` は既定 true。補正中に、表の `ik_hand_L`・`ik_hand_R` と、表に指定が無い側の既存の手のリンクの追従補助を使う。

オフにすると、この手 IK の制御を解除する。腰・足などの体の補正に加え、`L/R_hand_pos`・`L/R_elbow_pos` の骨へのずらしも続く（これらは体の補正の欄なので、UseHandIK で手・腕の補正のすべてが止まるわけではない）。機能全体を止めるには EnablePoseForce をオフにするか、量を０にする。

## 表で指定した手

`ik_hand_L`・`ik_hand_R` の target に、`female:k_f_legupR_00` のように「人:骨の名前」を指定する。female＝女１、female2＝標準３人の女２、male＝男。表の手は自分の骨にも付けられる。

x/y/z は、付け先の骨から見た位置のずらし（m）。量が０より大きいと手を付け替え、ずらしだけを量に比例させる。量を０から少し上げた時点で付け先が変わるので、付け替えそのものが少しずつ変わるわけではない。

表に手の行が無い状態、量０、機能オフ、体位・シーンの変更では、表で指定した手の付け替えを解除する。存在しない付け先には適用せず、ログに理由を出す。付け先の選び方は [編集の手順](POSE_FORCE_EDITOR.md)。

## 表に指定が無い手

補正中に、既存の手が相手のキャラの骨に付いていれば、補正後の骨に追従させる。骨に直接付いている場合は、位置の重みを１に保つ。

ゲームの手の同期の中継（Sync）が相手の骨を参照している場合も、既存の付け先・位置のずらし・回転で一時的な目標を更新する。この位置のずらしは、付け先の骨のローカルではなく、手を持つキャラの体の向きを基準にする。

既存のリンクが自分の側の骨を参照する場合（例: 自分の陰茎を握る手）、参加者の骨ではない家具などへのリンク、Sync 以外の中継は、この自動追従の対象外。表で自分の骨を明示した手の行とは別。

表で指定した手の行を消しても、相手への既存のリンクの追従に戻ることがある。手の付け替え・追従補助を止めたい場合は UseHandIK をオフにする。

## 復元と診断

一時的な目標を使い、元の中継の目標そのものは書き換えない。解除するときは、自分が持っている目標・重みだけを元に戻す。ほかの処理が目標を変えていた場合、その変更を古い目標で上書きしない。付け先が何度も変わる場合は `[PoseForce][手]` の警告を確かめる。

LogBones を有効にすると、IK の前の `[PoseForce][手IK]` と、各人の IK の後の `[PoseForce][手IK解後]` に、目標・中継元・付け先・同期の処理・重み・手との距離などを約１秒ごとに出す。最終の描画までのすべてのフレームを保証する値ではない。調べ終わったら LogBones をオフに戻す。

kPlug の書き出しには、ピストンの深さ（motion）で変わる手の値が１つある（開脚の正常位の SLoop の女の右手）。このプラグインでは、書き出したときの motion=0.5 の値で固定して使う。FK の回転と、体格・状態ごとの最終的な手の見た目は、すべてを確かめたわけではない。
