# 姿勢補正の使い方（ksPlugPoseForce）

## 対象と準備

KKS 通常版の２人挿入と、女性２人＋男性１人の標準３人挿入で、値の表にある体位・状態の姿勢を補正する。アナルは `A_` 付きの状態の値を使う。

**補正値はプラグインに入っていない。** 初めて使う前に、次のどちらかで値を用意する。

- KK 側で kPlugPoseForceExport を使って kPlug から書き出した表を取り込む（下の「保存ファイルと取り込み」、[書き出しの手順](POSE_FORCE_EXPORT.md)）。
- ほかの人が作って書き出した値（共有データ）を取り込む。
- 値の編集画面で、体位ごとに自分で値を足す（[編集の手順](POSE_FORCE_EDITOR.md)）。自分の値は書き出して、ほかの人と共有できる。

表が空のうちは、画面に「値の表が空」と表示して補正しない。kPlug 3.6.3／3.6.4 の書き出しを取り込んだ場合、KKS で使える値は通常の 26 体位と標準３人用の２体位。値のない体位・状態には、編集画面から自分で項目を追加できる。

VR・MMF（男２人＋女１人）・奉仕等・エステには対応しない。ksPlug が２人モードのまま招待キャラを加える場合も対象外（ゲーム本体の女性リストに女２として加わる標準の３人挿入とは別）。

## 最初に使う

1. 通常版の Hシーンで体位を選ぶ。
2. ConfigurationManager の `ksPlug Pose Force` → `PoseForce` を開き、`EnablePoseForce` をオンにする。既定はオフ。
3. 「調整の画面を開く」を押す。補正量と有効／無効だけの小さい画面。
4. 補正量を０より大きくする。０は補正なし、１は最大。初めての体位の量は０なので、体位を変えたときも表示を確かめる。

量はスライダー、−0.1／＋0.1、0／0.25／0.5／0.75／1 で変える。0.1 の増減は今の値に足し引きする（0.1 刻みに揃えない）。画面を閉じても補正は続く。

## キーと設定

| 設定 | 既定 | 用途 |
|---|---|---|
| EnablePoseForce | false | 機能全体のオン／オフ |
| Force | 0 | 今の体位の補正量。体位に入ると保存済みの量を読み込む |
| WindowKey | 未割り当て | 小さい調整画面の開閉 |
| EditorWindowKey | 未割り当て | 値の編集画面の開閉 |
| ForceUpKey／ForceDownKey | 未割り当て | 量を 0.1 増減。押し続けると 0.4 秒後から 0.1 秒ごとに繰り返す |
| UseHandIK | true | 手の付け先・ずらしと、既存の手のリンクの追従補助（[手 IK](POSE_FORCE_HAND_IK.md)） |
| LegFKAfterIK | false | 太もも・すねの回転（thighFK_rot・shinFK_rot）を IK を解いた後に足す。脚の IK が働いている体位でも脚が動くが、足が IK の目標から外れる（接地・接触がずれる）ことがある（下の「欄によって効かないとき」） |
| MoveUnlinkedLimbs | false | 手足のずらし（hand_pos・elbow_pos・foot_pos・foot_rot・knee_pos）を、ゲームの IK がその手足を自分の目標に付けていない体位・状態や、ゲームが IK を止めている状態でも効かせる。接触の位置がずれることがある（下の「欄によって効かないとき」） |
| ForceFootIK | false | foot_pos・foot_rot・elbow_pos・knee_pos の欄があるとき、ゲームの IK の付け先（相手の体など）に関係なく、足の IK とひじ・ひざの曲げを自分の目標（cf_pv_leg・cf_pv_elbo・cf_pv_knee）に重み 1 で付けて動かす。太もも・すねの欄がある脚は、LegFKAfterIK がオフなら足の IK を外す。ゲームが IK を止めている状態でも欄のある手足を動かす。相手の体との接触はずれる（下の「欄によって効かないとき」） |
| WheelAdjust | false | Hシーンで、右ボタンを押しながらホイールを回して補正量を変える（上で増やす・下で減らす）。右ボタンを押している間は何目盛りでも続けて変えられ、その間はゲームのカメラのズームを止める |
| WheelStep | 0.1 | WheelAdjust のホイール 1 目盛りで変える補正量（0.01〜1） |
| LogBones | false | 調査用の骨・手 IK のログ。通常はオフ |

キーは ConfigurationManager で割り当てる。WindowKey と EditorWindowKey は別のキーにする。ゲームに焦点がない間、文字の入力中、選択ダイアログを開いている間は、補正量のキーは効かない。マウスのホイールでの操作は無い。

量はアセット（体位）ごとに自動で保存する。操作が落ち着いて約１秒後と、体位の変更・Hシーンの終了時に保存する。同じアセットの通常とアナルは量を共有する。標準３人用は切り替えの前後でアセットが違うので、別々に覚える。Hシーンの外で ConfigurationManager から変えた量は、どの体位にも保存しない。

## 値を編集する

ConfigurationManager の「値の編集画面を開く」から、人・状態・補正項目・手の付け先を編集する。小さい調整画面と同時に表示できる。手順は [編集の手順](POSE_FORCE_EDITOR.md)。

数値は「補正量１のときの値」。編集は保存前からプレビューする。残したい変更は「保存」を押す。画面を閉じるだけなら未保存の編集を保持し、体位や Hシーンの変更・表の読み直し・取り込みでは捨てる。

「元に戻す（保存前へ）」は未保存の編集を戻す。「kPlug・内蔵の値に戻す…」は別ダイアログで復元元を選び、この体位の手動の編集を基準に戻す（必要なら、その後に保存する）。補正量の自動保存とは別の操作。

## 保存ファイルと取り込み

| ファイル・フォルダ | 内容 |
|---|---|
| BepInEx/config/kkttspj.kks.ksplugposeforce.cfg | 有効／無効、キー、手 IK などの設定 |
| BepInEx/config/ksPlugPoseForce/PoseForce.tsv | 自分の補正値の表（取り込んだ値・自分の編集・削除の指定など）。取り込みか、編集の保存で作られる。取り込みの対象にはならない |
| BepInEx/config/ksPlugPoseForce/PoseForceAmounts.tsv | 体位ごとの補正量。量を変えると自動で保存 |
| BepInEx/config/ksPlugPoseForce/import/ | 取り込むファイルを置くフォルダ（kPlug の書き出し・ほかの人の共有データ） |
| BepInEx/config/ksPlugPoseForce/export/ | 自分の値の書き出し先 |
| 各 TSV の .bak | ファイルを更新する直前の版 |

`import`・`export` のフォルダは、取り込み・書き出しの画面を開いたときに作られる。

### 取り込む

1. 取り込むファイルを `BepInEx/config/ksPlugPoseForce/import/` に置く。
   - kPlug の値: KK 側で書き出した主表 `kPlugPose_kPlug<版>.tsv`（[書き出しの手順](POSE_FORCE_EXPORT.md)）。診断用の `PoseForceDiagnostics_*.tsv` は置かない。
   - ほかの人の値: その人が書き出した `PoseForceShare_*.tsv`。ほかの人の `PoseForce.tsv` をそのまま置いてもよい（その人が自分で直した値だけを取り込む）。その場合はファイル名がデータの名前になるので、`Alice.tsv` のように人ごとに名前を変えて置く（`PoseForce.tsv` のままだと、別の人の表を取り込んだときに同じデータとして置き換わる）。
2. 「書き出しの取り込み画面を開く…」を押し、一覧から選んで「選んだファイルを取り込む」を押す。一覧には種類（kPlug の書き出し／共有データの名前）と行の数が出る。

同じ項目の値がいくつもあるときは、**自分で直した値 ＞ 共有データ ＞ kPlug の値 ＞ 内蔵の値** の順に使う。共有データ同士は、後から取り込んだ方を使う。同じファイル（同じデータの名前）を取り込み直すと、そのデータの値を新しい内容に置き換え、無くなった値は消す。自分で直した値と削除の指定は、取り込んでも変わらない。kPlug を更新したときも、新しい書き出しを同じように取り込む。

以前の版のように `BepInEx/config/ksPlugPoseForce/` の直下に置いた `kPlugPose_*.tsv` も、一覧に出る。

### 自分の値を書き出す（共有する）

「自分の値の書き出し…」（編集画面、または ConfigurationManager）で、データの名前と作者を入れて書き出す。範囲は全体位か、今の体位だけ。

- 書き出すのは、自分で編集して保存した値と、欄を消す指定だけ。取り込んだ kPlug の値・ほかの人の値、体位を止める設定、保存していない編集は含まない。
- `import` フォルダなどにある kPlug の書き出しと同じ値の行は、書き出さない（kPlug の値をそのまま配らないため）。ただし、kPlug の値を別の状態に写しただけの行などは見分けられないので、配る前に中身を確かめる。
- 書き出したファイル `export/PoseForceShare_<名前>_<日時>.tsv` を、受け取る人は自分の `import` フォルダに置いて取り込む。データの名前で見分けるので、更新版も同じ名前で書き出す。

### kPlug の値の代わりに内蔵の値を使う

内蔵の値（プラグインに入っている値。今の版には入っていない）と kPlug の値の両方がある体位では、kPlug の値を使う。kPlug の値を使いたくない体位は、内蔵の値を自分の値にする。

1. その体位で値の編集画面を開き、「kPlug・内蔵の値に戻す…」を押す。
2. 「内蔵の値を自分の値にする（この体位、…行、未保存）」を押す。
3. 見た目を確かめて「保存」を押す。

自分の値は kPlug・共有データの値より優先されるので、後から kPlug の書き出しを取り込み直しても、内蔵の値が使われる。

`PoseForce.tsv` を直接編集した場合は「値の表を読み直す」で反映する。表の形式は [値の表](POSE_FORCE_TABLE_FORMAT.md)。

## 補正されないとき

画面に出る理由と、EnablePoseForce・量・今の体位／状態を確かめる。値の表が空、値のない体位・状態、止めてある体位、体位を変えた直後は補正しない。手だけを確かめるときは UseHandIK も見る。

ゲームがその状態で女の IK を止めているときは「補正しています（女の IK が止まっている状態：…）」と出る。このときも体の骨の欄・太もも・すね・手首・指は補正する（kPlug と同じ）。手足の IK の目標の欄は、MoveUnlinkedLimbs か ForceFootIK がオンのときだけ効く（このプラグインがその手足だけを IK で動かす）。手の付け替えは効かない。

## 欄によって効かないとき

欄は種類ごとに効く条件が違う。編集画面で、ゲームの今の状態を選んでいると、欄ごとに「今の状態で: 効く／効かない（理由）」が出る。

| 種類 | 欄 | 効く条件 |
|---|---|---|
| 体の骨 | root_pos・waist_rot・spine_rot・spine_roll・shld_rot・hipShp_pos・footFK_rot・toeFK_rot | いつも（IK が止まっている状態でも） |
| 手足の IK の目標 | hand_pos・elbow_pos・foot_pos・foot_rot・knee_pos | ゲームの IK が、その状態でその手足を自分の目標（cf_pv_*）に付けているときだけ。相手の体に付いている手足（騎乗位の女の手など）や、IK が付いていない手足では動かない。MoveUnlinkedLimbs・ForceFootIK（hand_pos を除く）をオンにすると動く |
| 太もも・すね | thighFK_rot・shinFK_rot | 脚の IK が働いていないときだけ。働いていると、IK を解くときに脚の向きが決め直されて消える。LegFKAfterIK をオンにすると動く |
| 手首・指 | hand_rot・fingers_rot・thumb01_rot〜little03_rot | いつも。IK を解いた後に足す（手首は腕の IK の端なので、後に足さないと IK が向きを決め直す。指は IK の外） |
| 手の付け替え | ik_hand_L・ik_hand_R | IK が動いている状態で、UseHandIK がオンのとき |

- 足首から先（footFK_rot・toeFK_rot）は脚の IK の外なので、いつも効く。
- MoveUnlinkedLimbs: 相手の体などに付いている手足は、その付け先からずらす。IK が付いていない手足は、今の位置からずらした目標に付ける（IK で動かすようになる）。どちらも IK を解いている間だけで、ゲームが決めた付け先・重みは変えない。同じ手に手の付け替え（ik_hand）の行があれば、そちらを優先する。
- MoveUnlinkedLimbs（ゲームが IK を止めている状態）: その人の欄のある手足だけを、今の位置からずらした目標に付けて、このプラグインが IK を解く。体・肩・太ももは動かさず、欄の無い手足もそのまま。解く前のゲームの IK の設定（付け先・重み）は控えておき、解いた後に毎フレーム元に戻す。この脚は IK で決め直すので、太もも・すねの欄は LegFKAfterIK もオンにしないと効かない。
- ForceFootIK: foot_pos・foot_rot の欄がある足は、ゲームの付け先をやめて自分の cf_pv_leg（欄の値を足した位置・向き）に位置・回転とも重み 1 で付ける。elbow_pos・knee_pos は曲げの目標を自分の cf_pv_elbo・cf_pv_knee に重み 1 で付ける。MoveUnlinkedLimbs が今の付け先からずらすのに対して、こちらはアニメーションの目標の位置に付けるので、相手の体との接触は保たない。thighFK_rot・shinFK_rot の欄がある脚は、LegFKAfterIK がオフなら足の IK の重みを 0 にして太もも・すねを効かせる（その脚の foot_pos・foot_rot は効かない）。hand_pos は付け替えない（MoveUnlinkedLimbs で動かす）。どれも IK を解いている間だけで、解いた後に毎フレーム元に戻すので、欄の無い体位・状態ではゲームの IK のまま。補正量が 0 のときは付け替えない。MoveUnlinkedLimbs と一緒にオンにすると、ForceFootIK の対象の欄はこちらを優先する。ゲームが IK を止めている状態では MoveUnlinkedLimbs と同じに動かす。
- fingers_rot は、親指以外の 4 本の指の 3 つの関節すべてに同じ回転を足す。指の関節ごとの欄（例: L_index02_rot）と一緒に使うと、両方の値を足す。
- LegFKAfterIK: 太もも・すねを、IK を解いた後に回す。足や膝が IK の目標から外れるので、床や相手との接触がずれることがある。
- どちらも既定はオフ。オンにしても、自分の目標に付いている手足・脚の IK が働いていない脚の動きは変わらない。
- 手足の付け先と重みは、LogBones をオンにするとログの `[PoseForce][手足]` に約 1 秒ごとに出る。
